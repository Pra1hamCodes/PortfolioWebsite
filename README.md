## ✨ Overview

A cinematic, single-page portfolio website built from scratch with pure HTML, CSS, and JavaScript — no frameworks, no dependencies. Features a dark luxurious aesthetic with a black-and-gold palette, looping background video, ambient audio, scroll-linked animations, a cinematic intro sequence, and immersive micro-interactions throughout.

---

## 🎬 Features

| Feature | Description |
|---|---|
| **Cinematic Intro** | Full-screen video intro with skip button on page load |
| **Looping Video Background** | `sequence2.mp4` plays as a fixed fullscreen background behind all content |
| **Background Audio** | Ambient `bgaudio.mp3` starts on first user interaction (browser-safe) |
| **Scroll-Linked Image Sequence** | 102-frame golden-light sequence scrubbed by scroll position with narrative caption beats |
| **3D Horizontal Carousel** | Perspective-transformed project cards with scroll-driven rotation and scaling |
| **Winding SVG Timeline** | Animated experience timeline with cursor-reactive energy path and magnetic orb |
| **Custom Cursor** | Gold dot + ring cursor with magnetic snapping on interactive elements |
| **Typewriter Effect** | Rotating taglines in the hero section |
| **Scroll Reveal Animations** | Staggered, re-triggering entrance animations on all sections |
| **Mobile Responsive** | Hamburger nav, adapted layouts, and touch-friendly interactions |

---

## 📑 Sections

1. **Hero / Cinematic Stage** — Scroll-driven 102-frame golden-light sequence with narrative beats
2. **About** — Profile photo, bio, education timeline, and quick details
3. **About Me** — Extended personal narrative with key stats
4. **Skills** — Categorised technical arsenal (Programming, BI, ML/AI, Databases, Web, Business)
5. **Projects** — 12 project cards in a 3D horizontal carousel
6. **Experience** — Leadership & internship timeline with winding SVG path
7. **Achievements** — Awards & milestones (MSIC Winner, IEEE Paper, Robotics, Hackathons)
8. **Certifications** — Courses & training from NullClass, Devtown, Google, Udemy, etc.
9. **Connect** — Contact cards for LinkedIn, GitHub, Email, and Phone

## 🛠️ Tech Stack

| Layer | Technology |

| **Logic** | Vanilla JavaScript (no libraries or frameworks) |
| **Typography** | Google Fonts (Fraunces, Cormorant Garamond, Jost, DM Mono, Cinzel) + custom Makcasa font |
